# Week_04_Student_Management_Dashboard
Student Management Dashboard

A simple and responsive Student Management System built using HTML, CSS, and JavaScript.

Features:

Add new student records
Edit existing student details
Delete student records
Search students by name, roll number, or email
Filter students by course
Save data using browser localStorage
Responsive design for mobile and desktop

Technologies Used:
HTML5
CSS3
JavaScript
Browser localStorage
How to Run:
Download or clone this repository.
Open the project folder in Visual Studio Code.
Open index.html using the Live Server extension.
Project Structure
index.html — Page structure

style.css — Styling and responsive layout

script.js — Student management functionality
